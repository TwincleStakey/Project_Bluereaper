# BulletHeavenArt 기획 문서

> 계속 업데이트하는 문서예요. 결정된 내용은 "결정", 아직 정하지 않은 내용은 "열린 항목"에 둡니다.
> 최종 수정: 2026-11-06

## 1. 프로젝트 개요

- **장르:** 탑다운 탄막 슈터 (엔터 더 건전 계열의 시스템을 참고)
- **비주얼:** 3D 복셀 + 카툰 렌더링
- **테마:** 한국 요괴, 동양 다크 판타지
- **엔진:** Unity 6000.3.18f1, URP 17.3, Input System 1.19
- **프로젝트 경로:** `F:\UnityProject\BulletHeavenArt`

## 2. 레퍼런스 분석 원칙 (엔터 더 건전)

- Unity(Mono) 게임이라 `Assembly-CSharp.dll`은 dnSpy/ILSpy로 디컴파일되고, 에셋은 AssetRipper로 추출할 수 있다.
- 개인 공부용 분석은 회색지대다. 코드나 에셋을 그대로 써서 출시하는 것은 안 된다.
- **결정:** 구조(시스템, 수치, 루프)만 배운다. 아트, 코드, 세계관은 전부 새로 만든다.
- **진행 순서:**
  1. 기획 분석
  2. 아트 스타일 결정
  3. 시스템 클린 구현
  4. 막힐 때만 디컴파일한 코드를 참고

## 3. 아트 방향

### 결정
- 2D 픽셀은 방향이 아니다. **3D 복셀 탑다운 + 카툰 렌더링 + 한국 요괴**로 간다.
- **톤 레퍼런스:** 타래: 언바운드 (크래프톤/바운더리, 동양 다크 판타지 핵앤슬래시)
  - 어두운 배경, 발광 포인트, 동양 소품을 참고한다.
- **탄막 게임 스타일 조합:**
  - 연출: Nex Machina
  - 캐릭터: Shooty Skies식 박스형 복셀 요괴
  - 조명·카메라: Death's Door
- Nex Machina 이펙트를 그대로 따라 하면 화면이 안 읽혀서 탄막 게임에는 독이다. 아래 가독성 규칙으로 제한한다.

### 가독성 규칙
1. 바닥은 어둡고 저채도로.
2. 적 탄은 따뜻한 색, 내 탄은 차가운 색. 모양도 다르게.
3. 캐릭터는 외곽선, 큰 눈, 발밑 링.
4. 발광은 탄, 눈, 광원에만. 화려한 파편 연출은 적이 죽는 순간에만.

### 한국 테마 요소
- 도깨비불 (청록)
- 부적 탄 (주황·빨강)
- 단청
- 석등
- 갓 쓴 플레이어

## 4. 제작 분업 (복셀 퀄리티 기준)

| 퀄리티 | Claude 생성 가능 수준 | 비고 |
|---|---|---|
| 박스형 귀여운 복셀 (Shooty Skies, 형광 몬스터 계열) | 90% 이상 | 거의 그대로 사용 가능 |
| 중간 디테일 (사자탈 등) | 70~80% | 갈기, 곡선, 명암은 MagicaVoxel에서 다듬기 |
| Moenen급 고퀄 수작업 복셀 | 어려움 | 직접 제작 영역 |

- **분업안:** Claude가 파츠가 분리된 `.vox`를 생성하고, Kido가 MagicaVoxel에서 디테일을 덧칠한다.
