# BlueReaper 문서 색인

| 하려는 일 | 읽을 문서 |
| --- | --- |
| 작업을 시작하거나 적용 범위를 확인한다 | [에이전트 작업 지침](../AGENTS.md) |
| 주요 시스템, 씬 구성, 코드 진입점을 파악한다 | [시스템 지도](SYSTEM_MAP.md) |
| 변경 유형에 맞는 검증을 고르거나 작업을 인계한다 | [작업·검증 절차](WORKFLOW.md) |
| 플레이어·적의 등록, 피해, 자세, 사망, 회수나 필드 전환을 바꾼다 | [개체 수명 계약](contracts/UNIT_LIFECYCLE.md) |
| 페이즈, 패턴 선택, 시퀀스, 근거리·탄막·소환 효과를 바꾼다 | [적 패턴 계약](contracts/ENEMY_PATTERNS.md) |

시스템 지도는 현재 구조와 에셋 연결을 설명한다. 동작의 순서와 소유권을 확인할 때는 관련 계약을 읽는다. 변경에 영향을 받는 문서는 같은 작업에서 갱신한다.
