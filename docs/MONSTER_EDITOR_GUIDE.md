# 몬스터 편집툴 사용 가이드

Unity의 `Tools > BlueReaper > Monster Editor`에서 몬스터 프리팹과 연결된 데이터를 편집한다. 도구는 Edit Mode에서 사용한다.

## 1. 몬스터 열기 또는 만들기

- **기존 몬스터**는 Project 창의 프리팹을 **기존 몬스터 프리팹**에 지정하고 **기존 프리팹 열기**를 누른다. 프리팹 루트에 `Unit`, `Enemy`, `EnemyAI`가 있어야 한다.
- **새 몬스터**는 **더미 프리팹**을 지정한다. 기본 템플릿은 `Monster_1`이다. 확장자 없이 이름을 입력하고 등급을 고른 뒤, 화면에 표시된 두 경로를 확인하고 **더미로 새 몬스터 만들기**를 누른다. 이 버튼은 프리팹과 독립 스탯 에셋 `<이름>_Stats.asset`을 즉시 생성한다. 모델, 패턴, 페이즈 같은 나머지 에셋 참조는 템플릿에서 승계한다.

| 등급 | 프리팹 폴더 | 스탯·페이즈·패턴 데이터 폴더 |
| --- | --- | --- |
| `Normal`, `Elite` | `Assets/_Project/Prefabs/Monsters` | `Assets/_Project/Data/Monsters` |
| `Boss` | `Assets/_Project/Prefabs/Boss` | `Assets/_Project/Data/Bosses` |

등급을 바꾸면 기존 에셋은 현재 경로에 남고 **연결 확인**에 경고가 표시된다. 새로 생성하거나 복제하는 데이터는 편집 중인 등급의 폴더를 사용한다.

## 2. 스탯·페이즈·타겟 설정

| 탭 | 작업 |
| --- | --- |
| **기본 정보** | 등급과 보상 테이블을 연결하고 `UnitData`에서 최대 HP, 공격력, 이동 속도를 설정한다. |
| **페이즈** | 페이즈 에셋의 HP 임계값을 `1000`부터 내림차순으로 설정한다. `1000, 700, 350`은 1페이즈 시작, HP 70%·35% 이하에서 2·3페이즈 진입을 뜻한다. 일반 행동의 `Require Phase`를 지정한 뒤 각 페이즈에 표시되는 후보를 확인한다. |
| **타겟 규칙** | AI 추격의 시야·거리와 `Chase Target Rule`을 설정한다. 행동의 `Target Mode`는 `Inherit`으로 상위 대상을 이어받거나, `Select`로 자체 규칙을 사용하거나, `None`으로 타겟 접근 없이 실행하도록 설정한다. 필터와 정렬에는 어그로·HP·HP 비율·거리를 사용할 수 있다. |

스탯·페이즈 등의 값을 창에서 수정하려면 **이 에셋 편집**을 누른다. 공유 에셋은 저장 후 모든 참조에 영향을 준다. 이 몬스터 전용으로 편집하려면 **복제 후 연결**이 있는 참조 행에서 먼저 복제한다. **에셋 Inspector 열기**는 Project 에셋을 선택하므로, 외부 Inspector에서 한 편집은 몬스터 창의 저장·취소와 별도로 관리한다.

## 3. 패턴 연결과 효과 편집

1. **패턴** 탭에서 기존 에셋을 슬롯에 연결하거나, **연결 슬롯**과 이름을 지정하고 **행동 생성 후 연결**을 누른다. `Normal`은 페이즈별 일반 행동의 후보, `Spawn`은 스폰 시 실행하는 행동, `Death`는 사망 시 실행하는 단일 패턴이다. 일반·스폰 슬롯은 **시퀀스**를 선택할 수 있다.
2. 연결 행의 에셋 이름을 클릭한다. 기존 에셋을 함께 갱신하려면 **공유 에셋 편집**, 해당 연결만 바꾸려면 행의 **복제 후 연결**을 사용한다. 복제된 시퀀스는 원본의 스텝을, 복제된 패턴은 원본의 효과를 참조한다. 스텝이나 효과도 독립적으로 수정하려면 해당 행에서 추가로 복제한다.
3. 시퀀스에서 **스텝 생성 후 추가**를 누르거나 기존 패턴을 `Steps`에 연결한다. 배열의 위에서 아래로 실행되므로 순서를 확인한다. 개별 스텝의 `Require Phase`는 시퀀스 실행 중 다시 검사하지 않는다.
4. 단일 패턴 또는 스텝에서 **효과 종류**를 고르고 **효과 생성 후 추가**를 누른다. 기존 효과는 `Implementations`에 연결할 수 있다. 효과 편집을 마치면 **상위 편집으로 돌아가기**로 패턴이나 시퀀스를 다시 연다.

| 효과 | 입력과 확인 |
| --- | --- |
| `Melee` | 첫 판정과 판정 유지 시간, 피해 배율을 지정하고 프리팹의 `MeleeHitBox`를 확인한다. 한 패턴에 근접 효과를 여러 개 넣으면 첫 항목을 실행한다. |
| `Bullet` | Project의 탄 프리팹을 연결한다. 프리팹에 `ProjectileHitBox`와 3D Collider가 있어야 한다. 경로형은 경로 프리셋과 시작·제어·끝점을, 선형은 속도·수명을 설정한다. 발사 횟수·간격은 발사 회차를 제어하고, **탄별 지속 판정**은 개별 탄의 판정 구간을 설정한다. |
| `Area` | 시전자·필드 배치 기준과 도형을 선택한다. **배치 지연**은 **첫 판정** 이하여야 하며 **판정 유지 (초)**는 양수다. **배치까지만 대기**를 켜면 좌표 확정 뒤 해당 효과의 대기가 끝나고, 장판은 유지 시간 동안 계속 판정한다. 자폭 스텝은 범위 효과 종료까지 대기한다. |
| `Summon` | 시전자·타겟·필드 중심 중 소환 기준, 적 프리팹과 수량, 반경을 설정한다. 프리팹 배열과 수량 배열의 길이를 맞춘다. |

근접·범위는 첫 판정부터 유지 시간이 끝나기 전까지 겹침을 검사한다. **반복 판정**을 끄면 부위당 한 번, 켜면 반복 간격으로 나눈 구간마다 부위당 한 번이다. 전조, 발밑 좌표 고정, 사망 효과의 실행 조건은 [적 패턴 계약](contracts/ENEMY_PATTERNS.md)에서 확인한다.

### SceneView에서 확인하기

- **탄막**은 **XZ 탑뷰**에서 경로를 클릭하거나 **편집할 탄** 슬라이더로 선택한다. 경로형 탄은 S·C·E 핸들 또는 XYZ 입력으로 수정하고, **전체 경과 시간 (초)**이나 **재생**으로 발사 회차와 이동을 확인한다.
- **범위**는 **탑뷰에서 범위 보기**를 누르고, 윤곽선 또는 **편집할 도형**으로 기본·추가 도형을 선택한다. 중심·크기·방향을 조정하고 필요하면 **높이 편집**을 켠다. 상위 패턴의 시간 슬라이더에서는 전조를 포함한 범위 효과의 순서와 활성 구간을 확인한다.
- 미리보기 원점·시전자·필드 설정은 화면에만 적용된다. 실제 충돌과 피해, 애니메이션, VFX는 Play Mode에서 확인한다.

## 4. 공격·피격 판정과 모델 교체

1. **공격·피격 판정**에서 `Box`, `Sphere`, `Capsule` 중 모양을 고른다. 근접 공격에는 **공격 판정 추가**, 맞는 부위에는 **피격 판정 추가**를 사용한다. 두 판정은 별도 오브젝트에 두고 위치와 크기를 확인한다.
2. 피격 Collider는 `Hurtbox` 레이어에 둔다. 기존 Collider에 부위별 피해가 필요하면 **독립 피격 부위로 지정**을 사용한다. `Damage Reduction`은 `0`이 감소 없음, `0.25`가 25% 감소다. 같은 `Hurtbox`에 속한 여러 Collider는 한 부위로 집계하며, 머리와 몸통처럼 서로 다른 부위에 맞으면 감소율을 각각 적용해 공용 HP에 합산한다.
3. **모델·애니메이션**에서 Mesh·Materials를 교체하거나 **시각 모델 추가**로 모델 프리팹·FBX를 붙인 뒤 기존 더미 렌더러를 끈다. 루트 Animator의 Controller와 Avatar를 확인한다. 첫 레이어에 `Idle`, `Move`, 각 패턴의 `Motion Clip` 이름과 일치하는 상태를 두고 Float 파라미터 `MoveSpeed`를 설정한다. 본에 공격·피격 판정을 붙일 때는 저장 후 **Prefab Mode에서 계층 열기**로 위치를 편집한다.

## 5. 저장·취소·확인

1. 우측 **연결 확인**에서 경로·페이즈 후보·Collider·Animator 경고를 살펴보고 **변경 검토 · 저장**에서 저장 대상 프리팹과 에셋을 확인한다. 저장하면 새 행동·스텝·효과가 등급별 Data 폴더에 개별 `.asset`으로 생성된다. 외부에서 같은 프리팹이나 공유 에셋을 수정했다는 메시지가 나오면 외부 편집을 끝내고 저장된 버전을 다시 연 뒤 필요한 변경을 반영한다.
2. **변경 취소**는 화면에서 편집하던 내용을 버리고 마지막으로 저장된 프리팹을 다시 연다. 패턴 탭에서 저장 대기 중이던 행동·스텝·효과와 복제본은 이때 파일이 생성되지 않는다. **더미로 새 몬스터 만들기**로 이미 생성한 프리팹·스탯과, 기본 정보·페이즈의 **복제 후 연결** 대화상자에서 저장한 데이터 복제본은 디스크에 남는다.
3. 저장 후 프리팹을 다시 열어 에셋 참조와 시퀀스 순서를 확인한다. Play Mode를 시작하기 전에 창의 변경을 저장하거나 취소한다. 테스트 씬에서 몬스터를 스폰하고, 변경한 페이즈·행동 순서·공격과 피격·애니메이션을 확인한다.

## AI 에이전트 작업과 검증

1. 변경할 프리팹과 행동 슬롯을 식별하고 **프리팹 → 행동 또는 시퀀스 → 스텝 → 효과**의 참조를 따라간다. 연결 필드는 `EnemyAI.patterns`, `spawnPattern`, `deathPattern`, `EnemyPatternSequenceData.Steps`, `EnemyPatternData.Implementations`이다. 공유 에셋을 편집할 때는 같은 GUID를 참조하는 프리팹과 패턴을 확인한다.
2. 프리팹 구조와 저장 경로, 패턴 생성·복제 단계의 참조를 에디터 코드에서 확인한다. 에셋과 `.meta`를 함께 검토하고, 저장 후 다시 열어 참조와 스텝 순서를 대조한다. [프리팹 편집 코드](../Assets/_Project/Scripts/Editor/MonsterEditorWindow.cs) · [패턴 편집 코드](../Assets/_Project/Scripts/Editor/MonsterEditorWindow.Patterns.cs)
3. Unity 메뉴 `Tools > BlueReaper` 아래에서 작업에 맞는 검사를 실행한다. 배치 실행이 필요하면 아래 메서드를 Unity의 `-executeMethod`로 호출한다. 이 검사는 편집·데이터 검증에 해당한다. 실제 피해나 VFX 검증은 실행한 Play Mode 시나리오를 따로 기록한다.

| Unity 메뉴 | 검증 범위 | 배치 실행 메서드 |
| --- | --- | --- |
| `Check Monster Editor` | 프리팹 복제, 등급별 경로, 리소스 교체와 재임포트 | `BlueReaper.Data.Editor.MonsterEditorChecks.Run` |
| `Check Monster Pattern Authoring` | 등급별 행동·스텝·효과 저장, 재임포트와 저장 전 취소 | `BlueReaper.Data.Editor.MonsterPatternAuthoringChecks.Run` |
| `Check Hit Window` | 판정 구간의 경계, 부위별 중복 처리, 범위 미리보기 종료 시각 | `BlueReaper.Data.Editor.HitWindowChecks.Run` |
